Smart Hospital web app - stage 1

1. Open config.py and type your MySQL root password in DB_PASSWORD.
2. Install Flask once:   pip install flask
3. Start the app:        python app.py
4. Open http://127.0.0.1:5000 in your browser.

Demo logins (created by generate_data.py)
